# MS-4018 — TP Copilot dans PowerPoint (Retail360)

Parcours principal de **15 minutes** conforme au programme client, et ateliers facultatifs de **30 à 60 minutes** pour explorer davantage les fonctionnalités de Copilot et de PowerPoint.

## Fichiers
- `TP_MS4018_Copilot_PowerPoint_Retail360.md` : guide formateur et participant, pas-à-pas dans l’interface, prompts, ateliers et évaluation.
- `Brief_Retail360_Bilan_2025.docx` : source métier pour créer les diapositives.

## Prérequis
Microsoft 365 Copilot dans PowerPoint, compte autorisé et accès au briefing Word. Tester les options disponibles avant l’atelier : certaines fonctions Copilot dépendent de la version et du déploiement.

## Déroulé
1. Préparer le briefing et ouvrir Copilot.
2. Générer une présentation depuis le briefing.
3. Retravailler texte, design et notes.
4. Résumer et réorganiser les diapositives.
5. Vérifier les KPI et enregistrer.

Les fonctionnalités natives PowerPoint sont distinguées de celles de Copilot dans le guide.
